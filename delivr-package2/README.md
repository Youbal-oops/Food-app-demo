# Delivr Wireframe v2

Open `dist/index.html` in a browser — no server needed.

## Screens
- **Login** — role picker (Customer / Admin), sign in / sign up toggle
- **Home** — promo banners, category filter, featured items
- **Menu** — search, filter, veg/nonveg indicators, item detail sheets
- **Cart** — items, summary, place order
- **Track** — live status timeline, driver card, past orders
- **Account** — profile, order history, addresses, payments, refer, help (all open sheets)
- **Admin** — orders + stats, menu toggle/add, staff, settings + promo management

## Dev
```
npm install && npm run dev
```
